# Northstar Retail Analytics

A portfolio project exploring messy retail transaction data using Python, pandas, SQL, and business intelligence.

## Tools
- Python / pandas
- DuckDB
- SQL
- Looker Studio
- Git / GitHub

## Goal
Transform messy source-system extracts into trustworthy analytical data, answer business questions, and communicate findings through an interactive dashboard.

## Important
The `data/raw` files intentionally contain data-quality problems. Do not overwrite the raw data. Create cleaned/processed outputs separately.

## Suggested project progression
1. Profile the raw data with pandas.
2. Identify and document data-quality issues.
3. Clean and standardize the data.
4. Query the cleaned data using SQL.
5. Perform exploratory analysis.
6. Build a BI-ready dataset.
7. Create a Looker Studio dashboard.
8. Document findings and limitations.
